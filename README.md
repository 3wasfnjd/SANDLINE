# SANDLINE — خط الرمل

## فكرة المستودع
لعبة معارك تكتيكية للمتصفح، يقود فيها اللاعب فصيل حرس الواحة ضد خصم آلي للسيطرة على مواقع داخل خريطة واحدة.

## الخدمات والمزايا
- إدارة فرق مشاة ومدرعة بأدوار قتالية مختلفة.
- أوامر التحرك والهجوم والثبات والانسحاب والسيطرة على ثلاث نقاط.
- قتال يتأثر بالغطاء والارتفاع والالتفاف وتماسك الفرق.
- تحكم باللمس ولوحة المفاتيح، ومباريات قابلة للإعادة دون حساب أو خادم.
